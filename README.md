# 🍜 Mie Cap DOKAR - Interactive Product Knowledge Web

Website **Product Knowledge & Eksiklopedia Interaktif** untuk **Mie Cap DOKAR** (Tradisi Olahan Singkong Gaplek & Tapioka khas Wonogiri - Solo Raya).

Dibangun dengan desain elegan, warna-warna *soft* (Cream, Warm Terracotta, Sage Green, Oatmeal), tombol kurva melengkung (*curved pill buttons*), dan animasi halus yang tidak kaku.

---

## ✨ Fitur Utama

1. **🌟 Katalog Produk Interaktif & Spec Sheet**:
   - Varian **Losspack (Curah 5 Kg)** untuk warung & HOREKA.
   - Varian **Kemasan Retail (20 Pcs x 250g / 5 Kg)** untuk display toko & sembako.
   - Varian **Agal Super (Patahan Berkualitas)** untuk industri kerupuk & seblak.
   - Varian **Kemitraan Resto (Custom)** dengan spesifikasi ketebalan khusus.
   - Dilengkapi tabel spesifikasi teknis, daya mekar, masa simpan, serta lembar cetak PDF.

2. **📊 Kalkulator Porsi & Keuntungan (HOREKA Profit Simulator)**:
   - Menghitung daya mekar (*yield ratio* 3.0x), modal bahan mie per porsi (hanya ~Rp 600/porsi), potensi omzet, dan estimasi margin laba kotor.

3. **🍳 Dapur Kuliner & Digital Cooking Timer**:
   - Panduan memasak langkah demi langkah untuk Mie Goreng Jawa, Mie Bakso/Soto, Seblak Pedas, dan Mie Nyemek Godhog.
   - **Digital Cooking Timer** bawaan dengan visual progress melingkar dan audio chime lembut saat waktu rebus selesai.

4. **🌾 Cerita Bahan Baku & Matriks Perbandingan Mutu**:
   - Edukasi keunggulan sari pati gaplek Wonogiri & tapioka murni tanpa pengawet sintetik vs mie basah pasar dan mie instan.

5. **🏭 Visualisasi 6 Tahap Produksi Higienis**:
   - Dari ladang singkong Wonogiri hingga pengemasan standar SOP 2026.

6. **🏆 Kuis Pemahaman Produk (Training Sales & Mitra)**:
   - Kuis interaktif 5 soal dengan penjelasan otomatis dan lencana skor.

7. **❓ Smart FAQ & Pencarian Cepat**:
   - Filter pencarian langsung dan accordion tanya jawab seputar penyimpanan, pengiriman grosir, dan tips memasak.

8. **💬 Formulir Pemesanan & WhatsApp Direct Builder**:
   - Generator pesan instan untuk sampel gratis, order grosir, atau kemitraan resto.

## 🚀 Cara Menjalankan

### Cara 1: Double-Click File Launcher (Khusus Mac)
Cukup klik ganda file:
```bash
Buka_DokarKnowledge.command
```
di dalam folder `memoria`.

### Cara 2: Melalui Terminal
```bash
cd /Users/skyjad/Documents/memoria/dokar-product-knowledge
npm run dev
```
Buka browser di `http://localhost:5176`.
