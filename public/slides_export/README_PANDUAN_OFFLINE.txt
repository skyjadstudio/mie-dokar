CARA PAKAI PADA VIDEOTRON / TV:
--------------------------------------------------------------------------------
- Opsi A (Flashdisk / USB):
  Copy semua file `slide_1.png` s/d `slide_8.png` ke Flashdisk. Colokkan ke port USB di Videotron / TV, lalu pilih menu 'Photo/Slideshow' -> set mode Repeat / Putar Berulang.
  
- Opsi B (Media Player / PC Videotron):
  Buka file `videotron_offline_player.html` di Google Chrome atau browser apapun. Tekan huruf 'F' pada keyboard untuk beralih ke Fullscreen. Slideshow akan berputar otomatis secara loop tanpa batas.
  
- Opsi C (PDF Viewer / Adobe Acrobat):
  Buka `videotron_mie_dokar_16_9.pdf` di Adobe Acrobat atau PDF Reader, pilih menu 'View' -> 'Full Screen Mode' (Ctrl+L atau Cmd+L).
